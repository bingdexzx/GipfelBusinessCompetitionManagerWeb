## 2. 关键实测结果

### 2.1 银行流水账（用例 10）

写入前模板状态（离线解析原文件）：第 3 行仅 `D3=0` 与 `F3` 公式；第 4 行起只有预置日期 `46232` 与余额列公式，**无序号/金额/摘要**。

| 调用 | 落点 | 实际结果 | 判定 |
| --- | --- | --- | --- |
| add=1000 / C001 | 第 3 行 | A3=2026-09-10、C3=1、D3=1000、F3=`=B3+D3-E3`、G3=`C001 合同收款` | ✅ 首行公式正确 |
| minus=300 / C002 | 第 4 行 | A4=2026-09-10、**C4=2（正确递增）**、E4=300、F4=`=F3+D4-E4`（链式保持）、G4=`C002 合同付款` | ✅ 余额 700 |
| 全零 / C003 | 第 5 行 | A5=2026-09-10、**C5=3**、F5=`=F4+D5-E5`、G5=`C003 空值` | ✅ |

- 写入后第 6~9 行 F 列缓存值由 0 变为 700（模板为共享公式，Excel 重算后余额链自动延续）→ **无余额断裂**；
- `entries_to_assets_money` = `银行流水账!$F$5`；
- 与上一轮（旧账套）结论差异：旧账套第 4~6 行残留历史序号 1/2/3，曾导致"序号重复 1,1,2、F4 被改写为首行式、余额 1000→−300"；**新账套无该残留，此三项异常不再复现**（撤销上一轮②③判断）。

## 5. 修改建议（未改动任何代码）

1. `add_book_entries`：如需保留模板预置日期，写入前判断该行是否已有日期/数据并顺延（对应①）；
2. `__init__`：文件不存在时 `raise FileNotFoundError(f"工作簿不存在: {file}")`（对应④）；
3. `add_book_item`：`sht[shtTT+2, shtTT-1]` 改显式行列号（对应⑥）；
4. 每个 add 方法加异常保护并在 `finally` 中 `xlapp.quit()`；长循环改为一次性读取整列 `Range.value` 以减少 COM 往返（缓解 §3）；
5. 复测顺序建议：正常 Excel 环境依次跑 `20_item_raw`（插行/出库）→ `30_item_part` → `31_item_product` → `40_assets`（负债/损益）→ `60_debug_visible`。
